# Dopamine Tracker - Quit your addiction

Dopamine Tracker is a mobile app designed to help users quit their dopamine triggers. A dopamine trigger is anything that causes an addiction (for example cigarettes, alcohol, food, etc.). Dopamine Tracker lets you track your progress daily. The app is built with Flutter and Gemini in Cline and works offline. There is an option to save and restore your data in a local JSON file.

### It's a vibe-coded fork of https://codeberg.org/retiolus/ExHale. Thanks to them for the base of the app and to Gemini for the fork. I'm only a puzzler.

## Features

- Quit Addiction Tracker: Tracks the time since the user's last dopamine trigger, triggers avoided, and money saved
- Data Export: Save your progress with a simple JSON file
- Privacy-Focused: Works fully offline, does not require any internet connection
- Addiction Calendar: see your progress as a calendar of daily dopamine triggers
- Heart rate and stress sync with Health Connect, so you can see why you use your dopamine trigger
- Manual emotion tracking, so you can see why you use your dopamine trigger

Note: Stress isn't actually stored in Health Connect, so the app uses different measures to estimate it.
